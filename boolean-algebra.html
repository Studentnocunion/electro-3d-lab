Introduction to Boolean Algebra

Boolean Algebra is a mathematical system used to analyse, represent and simplify digital logic circuits. It was introduced by mathematician George Boole.

Boolean Variables

Boolean variables can have only two possible values:

  • 0: Represents LOW or FALSE.
  • 1: Represents HIGH or TRUE.

Basic Boolean Operations

  • AND (·): Output is 1 only when both inputs are 1.
  • OR (+): Output is 1 when at least one input is 1.
  • NOT (bar): Produces the opposite value of the input.

Example

If A = 1 and B = 0:

  • A · B = 0
  • A + B = 1
  • NOT A = 0

Boolean Algebra is widely used in logic gate design, computer processors, digital systems and VLSI circuits.

Basic Boolean Laws

1. Identity Law

A + 0 = A

A · 1 = A

2. Null Law

A + 1 = 1

A · 0 = 0

3. Idempotent Law

A + A = A

A · A = A

4. Complement Law

A + A̅ = 1

A · A̅ = 0

5. Involution Law

(A̅)̅ = A

6. Commutative Law

A + B = B + A

A · B = B · A

7. Associative Law

(A + B) + C = A + (B + C)

(A · B) · C = A · (B · C)

8. Distributive Law

A · (B + C) = (A · B) + (A · C)

A + (B · C) = (A + B) · (A + C)

Important Boolean Theorems

1. Absorption Theorem

A + (A · B) = A

A · (A + B) = A

2. Redundancy Theorem

A + (A̅ · B) = A + B

A · (A̅ + B) = A · B

3. Consensus Theorem

(A · B) + (A̅ · C) + (B · C) = (A · B) + (A̅ · C)

4. De Morgan's First Theorem

(A · B)̅ = A̅ + B̅

5. De Morgan's Second Theorem

(A + B)̅ = A̅ · B̅

Why are these theorems important? They help simplify Boolean expressions and reduce the number of logic gates required in digital circuits.

De Morgan's Theorems

De Morgan's Theorems explain how to transform complemented AND and OR expressions into equivalent Boolean expressions.

First Theorem — Complement of AND

Formula:

(A · B)̅ = A̅ + B̅

Meaning:

The complement of an AND operation is equivalent to the OR operation of the complemented inputs.

Example:

If A = 1 and B = 1:
(1 · 1)̅ = 0
1̅ + 1̅ = 0 + 0 = 0

Second Theorem — Complement of OR

Formula:

(A + B)̅ = A̅ · B̅

Meaning:

The complement of an OR operation is equivalent to the AND operation of the complemented inputs.

Example:

If A = 1 and B = 0:
(1 + 0)̅ = 0
1̅ · 0̅ = 0 · 1 = 0

Applications

  • Simplification of Boolean expressions.
  • Conversion between AND, OR and NOT operations.
  • Design of NAND and NOR circuits.
  • Digital circuit optimization.

Boolean Expression Simplification

Boolean expression simplification reduces a logical expression to an equivalent but simpler form. This can reduce the number of gates needed in a circuit.

Example 1 — Idempotent Law

Given: A + A

Using: A + A = A

Answer: A

Example 2 — Complement Law

Given: A + A̅

Using: A + A̅ = 1

Answer: 1

Example 3 — Absorption Law

Given: A + (A · B)

Using: A + (A · B) = A

Answer: A

Example 4 — Distributive Law

Given: A · (B + C)

Using: A · (B + C) = AB + AC

Answer: AB + AC

Example 5 — De Morgan's Theorem

Given: (A · B)̅

Using: (A · B)̅ = A̅ + B̅

Answer: A̅ + B̅

Why Simplification Matters

  • Reduces the number of logic gates.
  • Can reduce circuit complexity and cost.
  • Can reduce power consumption.
  • Can improve circuit performance.

Boolean Algebra Technical Glossary

  • Boolean Algebra: Mathematical system used to represent and simplify logical expressions.
  • Boolean Variable: A variable that can have only two values, 0 or 1.
  • Boolean Expression: An expression formed using Boolean variables and logical operators.
  • Logical Operator: An operation such as AND, OR or NOT.
  • Complement: The opposite logical value of a Boolean variable.
  • Identity Law: A law stating that A + 0 = A and A · 1 = A.
  • Idempotent Law: A law stating that A + A = A and A · A = A.
  • Distributive Law: A law describing how AND and OR operations distribute over each other.
  • Absorption Law: A law used to eliminate redundant terms from Boolean expressions.
  • De Morgan's Theorems: Rules for transforming complemented AND and OR expressions.
  • Expression Simplification: Reducing a Boolean expression to an equivalent simpler form.
  • Logic Circuit: An electronic circuit that performs logical operations.
