Logic Gate Boolean Expressions

AND Gate

Y = A · B

Output is HIGH only when both inputs are HIGH.

OR Gate

Y = A + B

Output is HIGH when at least one input is HIGH.

NOT Gate

Y = A̅

Output is the complement of the input.

NAND Gate

Y = (A · B)̅

Output is the complement of AND.

NOR Gate

Y = (A + B)̅

Output is the complement of OR.

XOR Gate

Y = A ⊕ B

Output is HIGH when the inputs are different.

XNOR Gate

Y = (A ⊕ B)̅

Output is HIGH when the inputs are equal.

Applications of Logic Gates

1. Computers and Processors

Logic gates perform arithmetic, logical operations and decision-making inside processors.

2. Memory Circuits

Logic gates are used in memory control circuits and digital storage systems.

3. Digital Clocks

Logic circuits help control timing, counting and display operations.

4. Communication Systems

Used in digital signal processing, encoding and data transmission circuits.

5. Security Systems

Used to combine sensor signals and implement digital access-control logic.

6. Industrial Automation

Used in control systems, digital controllers and automated machines.

7. VLSI Design

Logic gates are fundamental building blocks of integrated circuits and digital chips.

Logic Gates Quick Revision Notes

  • Logic Gates: Basic building blocks of digital circuits.
  • Binary Values: 0 represents LOW and 1 represents HIGH.
  • AND Gate: Output is 1 when all inputs are 1.
  • OR Gate: Output is 1 when at least one input is 1.
  • NOT Gate: Produces the opposite of its input.
  • NAND Gate: Complement of AND.
  • NOR Gate: Complement of OR.
  • XOR Gate: Output is 1 when inputs are different.
  • XNOR Gate: Output is 1 when inputs are equal.
  • Universal Gates: NAND and NOR.
  • Truth Table: Shows outputs for every possible input combination.
  • Boolean Algebra: Mathematical system used to represent digital logic.

Logic Gates Technical Glossary

  • Logic Gate: An electronic circuit that performs a logical operation.
  • Boolean Algebra: A mathematical system used to represent and simplify digital logic.
  • Binary: A number system that uses only 0 and 1.
  • Logic Level: The voltage range representing binary LOW or HIGH.
  • Truth Table: A table showing all possible input combinations and their outputs.
  • Universal Gate: A gate, such as NAND or NOR, that can be used to construct any logic function.
  • Complement: The opposite logical value of a signal.
  • Propagation Delay: The time taken for a change in input to affect the output.
  • Fan-In: The number of inputs a logic gate can accept.
  • Fan-Out: The maximum number of standard logic inputs that one gate output can drive.
